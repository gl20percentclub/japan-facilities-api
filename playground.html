🔍 かんたん検索

🦆 SQL（編集して実行できます）

かんたん検索を使うと SQL がここに反映されます。列は全件CSVと同じ prefecture / city / city_raw / name / name_kana / business_type / address / lat / lng / geocoding_level / phone / license_no / license_date / expire_date / sources / licenses の16列です。

SQL の例を見る 
# 業種ごとの件数を集計
SELECT business_type, count(*) AS n
FROM read_parquet('<都道府県のParquet URL>')
GROUP BY 1 ORDER BY n DESC LIMIT 20;

# 市区町村で絞り込み
SELECT name, address, phone
FROM read_parquet('<都道府県のParquet URL>')
WHERE city = '那覇市' AND business_type LIKE '%飲食店%'
LIMIT 100;

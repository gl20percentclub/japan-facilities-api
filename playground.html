🛝 検索プレイグラウンド

全国の飲食施設データ（食品営業許可・届出）を、検索API でその場で検索できます。 キーワード（名称・カナ・住所・市区町村を横断）に加えて、地図の表示範囲内（bbox）や 中心から近い順（center + radius）の検索も試せます。登録・APIキー不要です。

トップ プレビュー地図 出典・ライセンス GitHub

検索APIのエンドポイントが設定されていません。
このページの URL に ?api=<検索APIのURL> を付けてアクセスするか、 playground.html 内の DEFAULT_API_URL を設定してください。

🔍 検索

📡 API リクエスト

—

この GET リクエストがそのまま検索 API の使い方です。curl やアプリからも同じ URL で呼べます。 レスポンスは { count, results: [{ name, name_kana, prefecture, city, address, business_type, lat, lng, level }] } の JSON です。

curl での例を見る 
# キーワード検索
curl -sG "<検索APIのURL>" \
  --data-urlencode "q=ラーメン" \
  --data-urlencode "limit=5"

# 東京駅周辺 10km の「カフェ」を近い順に
curl -sG "<検索APIのURL>" \
  --data-urlencode "q=カフェ" \
  --data-urlencode "center=139.767,35.681" \
  --data-urlencode "radius=10000"

# 地図の表示範囲（bbox = minLng,minLat,maxLng,maxLat）で絞る
curl -sG "<検索APIのURL>" \
  --data-urlencode "q=カフェ" \
  --data-urlencode "bbox=139.60,35.60,139.80,35.75"

📋 結果

キーワードを入れて「検索」を押してください。

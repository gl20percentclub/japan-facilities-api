日本全国の飲食施設オープンデータを
そのまま使える API に

全国の自治体が公開する食品営業許可・届出のオープンデータを毎週自動でクロールし、 全国共通フォーマットへの正規化と緯度経度の付与を行って、静的 API として配信しています。

特徴

バラバラの形式で公開されている自治体データを、1つの使いやすい形にまとめています。

🗾

全国をカバー

47 都道府県・1,900 以上の市区町村。都道府県 > 市区町村 の階層で、必要な地域だけを取得できます。

📍

緯度経度つき

座標が無い元データも normalize-japanese-addresses でジオコーディングして補完。精度レベルも一緒に返します。

🧹

形式を正規化

自治体ごとに違う列名・文字コード・市区町村表記を統一し、同じスキーマの JSON にそろえています。

🔄

毎週自動更新

GitHub Actions が毎週クロールして再配信。元データの差し替えにも追従します。

📦

好きな形式で

市区町村別 JSON、施設名検索用インデックス、全国結合 CSV、地図用ベクトルタイルを用意。

🆓

静的配信で無料

GitHub Pages でホスティング。登録・認証・レート制限はありません。CORS も開放済みです。

クイックスタート

ベース URL は https://gl20percentclub.github.io/japan-facilities-api/api/。 取得したい市区町村の data.json を叩くだけです。

1. 収録されている都道府県・市区町村の一覧を取る

curl https://gl20percentclub.github.io/japan-facilities-api/api/facilities/index.json

2. 市区町村の全施設を取る（日本語パスは URL エンコードする）

curl "https://gl20percentclub.github.io/japan-facilities-api/api/facilities/%E6%B2%96%E7%B8%84%E7%9C%8C/%E9%82%A3%E8%A6%87%E5%B8%82/data.json"

3. JavaScript から使う

const BASE = 'https://gl20percentclub.github.io/japan-facilities-api/api';

// 那覇市の全施設を取得
const res = await fetch(
  `${BASE}/facilities/${encodeURIComponent('沖縄県')}/${encodeURIComponent('那覇市')}/data.json`
);
const { data } = await res.json();
console.log(data[0].name, data[0].lat, data[0].lng);

4. 地図に出す（MapLibre GL JS・タイルサーバー不要）

map.addSource('facilities', {
  type: 'vector',
  tiles: ['https://gl20percentclub.github.io/japan-facilities-api/api/tiles/{z}/{x}/{y}.pbf'],
  minzoom: 6, maxzoom: 12,
});
// レイヤ名は "facilities"、属性は name / business_type / pref / city

配信している形式

用途に合わせて選べます。すべて同じベース URL 配下の静的ファイルです。

形式パス用途
市区町村別 JSON api/facilities/{都道府県}/{市区町村}/data.json ある地域の全施設を、全項目つきで取得する。もっとも基本的な形式です。
検索インデックス api/search-index.json（都道府県別に分割） 施設名の横断検索向けの軽量な索引。名前・住所・座標だけを配列で持ちます。
全国結合 CSV api/facilities-all.csv.gz（約 60MB / 非圧縮 約 540MB） Excel・pandas・BI ツールでまとめて分析する。UTF-8 BOM 付きです。
ベクトルタイル api/tiles/{z}/{x}/{y}.pbf（z6–12） 地図にそのまま重ねる。MapLibre GL JS から直接読めます。

各項目の詳細は API リファレンス、 自治体ごとの収録状況は 収録状況一覧 を参照してください。

出典・ライセンス

本サービスは各自治体・厚生労働省が公開するオープンデータを加工・統合したものです。 利用時の出典表示は、ライセンスごとに求められる形式が異なります。

📢 出典表示文は 出典・ライセンス表示ページ にまとめています。
全 98 ソースの出典 URL とライセンス、およびそのまま貼れる出典表示文を一覧化しています。
緯度経度は本サービスが独自に付与した参考情報です。 自治体が提供しているものではなく、住所からのジオコーディング結果のため、実際の所在地と異なる場合があります。
本サービスは各自治体の公式サービスではありません。 内容の正確性・完全性・最新性を保証するものではないため、正式な情報は各自治体の公開情報をご確認ください。

データソースの追加も歓迎です

未収録の自治体は config/sources.yaml に 1 エントリ追加するだけで取り込めます。 バグ報告・データ品質の問題報告・ドキュメント改善も歓迎です。
